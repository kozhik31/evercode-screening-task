#### Backend-приложение на Node.js и Express для работы с криптовалютами, адресами и балансами. Приложение позволяет хранить список отслеживаемых криптовалют и адресов, получать актуальные цены, проверять баланс адресов через внешний API и обновлять данные в базе.

## Стек технологий

* Node.js
* Express.js
* SQLite
* Axios / Fetch API
* JWT
* Swagger / OpenAPI
* Jest
* Supertest

## Возможности приложения

* Авторизация через JWT-токен
* CRUD для криптовалют
* CRUD для криптовалютных адресов
* Получение актуальной цены криптовалюты
* Получение баланса адреса через внешний API
* Обновление балансов адресов
* Централизованная обработка ошибок
* Документация API через Swagger
* Тестирование роутов с помощью Jest и Supertest



Запуск приложения:

```txt
npm start
```

Запуск тестов:

```txt
npm test
```

После запуска сервер будет доступен по адресу:

```txt
http://localhost:3000
```

## Документация API

Swagger-документация доступна по адресу:

```txt
http://localhost:3000/api-docs
```

## Авторизация

Для защищенных эндпоинтов используется JWT-токен.

Токен передается в заголовке `Authorization` в формате Bearer Token:

```txt
Authorization: Bearer <JWT_TOKEN>
```

Если токен отсутствует или некорректен, сервер вернет ошибку авторизации.
