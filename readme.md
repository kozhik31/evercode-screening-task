# Evercode Node.js Task

Тестовое задание на работу с модулями в Node.js.

## Описание

В проекте реализованы отдельные модули для хранения конфигурации приложения и логирования сообщений.

## Структура проекта

```text
src/
├── config.js
├── logger.js
├── scheduler.js
```

## Запуск

```text
npm start
```
